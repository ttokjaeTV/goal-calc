# 목표금액 계산기 · 똑재TV

목표금액까지 **매달 얼마씩**, **몇 년**이 걸리는지, **지금 계획대로면 얼마**가 모이는지 계산하는 단독 HTML 계산기입니다.

- 사이트: https://ttokjaetv.github.io/goal-calc/
- 3가지 모드: 필요한 월 적립액 / 달성 기간 / 만기 금액
- 물가 반영: 목표금액을 '지금 돈 가치' 또는 '달성 시점 금액' 기준으로 선택
- 수익률 시나리오(3·5·7·9% + 입력값) 비교
- 종목으로 수익률 정하기: 배당 재투자 계산기와 같은 프리셋 55종(최대 5종목·비중) → 연 수익률 = 배당률(최근 12개월 실지급 ÷ 종가, portfolio-sheet-data) + 주가성장률(가정치). 기본은 현금흐름 역산 계산기와 같은 보수적 보정(주가성장률 2.5%p↓, 상한 10%·커버드콜 8%)
- 연차별 상세 표, 입력값이 담긴 공유 링크

## 계산 방식
- 매월 말 적립, 연 수익률 R을 월 복리 `(1+R)^(1/12) - 1`로 환산 (현금흐름 역산 계산기와 동일)
- 세금·수수료를 빼지 않은 세전 기준

## 주소로 값 넘기기
금액은 만원 단위입니다.

```
?mode=pmt|time|fv&goal=50000&current=3000&monthly=100&years=20&rate=6&inflation=2.5&basis=today|future
```

- `from=retirement`: 현금흐름 역산 계산기에서 넘어온 경우 안내 문구를 띄우고, 필요 자산은 이미 물가가 반영된 금액이므로 `basis=future`로 계산
- `inflation=0`이면 물가 반영을 끔
